# homebrew-tap

Personal [Homebrew](https://brew.sh) tap for [@SantiagoCoronado](https://github.com/SantiagoCoronado)'s tools.

## Install

```sh
brew install santiagocoronado/tap/espresso
```

## Formulae

| Formula | Description |
| --- | --- |
| [`espresso`](https://github.com/SantiagoCoronado/espresso) | Keep your Mac awake from the terminal ☕ — a tiny Amphetamine with ASCII art |
